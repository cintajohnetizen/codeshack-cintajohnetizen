# Git Basics

What Is Git?

Git is a distributed version control system used to track changes in files and manage project history.

 What Is Version Control?

Version control records changes made to a project over time. It allows developers to review previous versions, recover work, and collaborate more safely.

Git vs GitHub

Git is software that manages version history. GitHub is an online platform that hosts Git repositories and provides collaboration features.

Important Git Areas

1. **Working directory:** The files you edit.
2. **Staging area:** The changes selected for the next commit.
3. **Local repository:** The committed project history stored by Git.
4. **Remote repository:** A repository hosted online, such as on GitHub.

Basic Git Workflow

```bash
git status
git add README.md
git diff --staged
git commit -m "Update project documentation"
git push
```

This workflow checks changes, stages them, reviews them, records a commit, and uploads the commit when the branch is correctly connected to a remote.

Conclusion

Git helps developers maintain a history of their work and manage changes in a structured way.

## Benefits of Git

- Tracks changes to project files.
- Maintains a history of commits.
- Supports separate feature branches.
- Helps developers collaborate on projects.
