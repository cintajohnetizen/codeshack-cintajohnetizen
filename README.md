# Developer Handbook

## Introduction

Welcome to my Developer Handbook, created as part of the CodeShack Week 1 Git and GitHub CLI task.

This project documents my learning of Git fundamentals, version control, branching, and collaborative software development.

## Objectives

- Understand essential Git commands.
- Track project changes using commits.
- Create and manage feature branches.
- Synchronise local repositories with GitHub.
- Understand collaborative development workflows.

## Repository Contents

- `README.md`: Introduction to the project.
- `git-notes.md`: Essential Git commands with explanations and examples.
- `handbook/git-basics.md`: Introduction to version control and Git.
- `handbook/branching.md`: Creating and managing branches.
- `handbook/collaboration.md`: Collaboration and pull request workflows.

## Tools Used

- Git
- GitHub
- GitHub CLI
- Visual Studio Code
- Markdown

## Learning Outcomes

By completing this project, I aim to understand how developers track changes, manage different versions of files, and collaborate through separate branches.
